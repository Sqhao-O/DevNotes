# 段落

第一段文字。

第二段文字。段落之间至少保留一个空行。

```md
第一段文字。

第二段文字。段落之间至少保留一个空行。
```

## 强制换行

这一行结尾有两个空格，  
所以这一句显示在下一行。

```md
这一行结尾有两个空格··
所以这一句显示在下一行。
```

> [!warning] 空格不易察觉
> 上例中的 `··` 仅表示两个空格，实际输入时不要写入中点。更易维护的做法是用空行拆分段落；只有确实需要行内换行时才使用两个尾随空格。

## 转义字符

\*这不是斜体\*  
\# 这不是标题  
\[这不是链接\](https://example.com)  
1\. 这不是有序列表

```md
\*这不是斜体\*
\# 这不是标题
\[这不是链接\](https://example.com)
1\. 这不是有序列表
```

## 特殊字符

`&lt;` 显示为小于号，`&gt;` 显示为大于号，`&amp;` 显示为与号。

```md
`&lt;` 显示为小于号，`&gt;` 显示为大于号，`&amp;` 显示为与号。
```

## 实用约定

文件名、命令、环境变量、HTTP 方法、配置项和短代码片段用行内代码；一句话的重点用加粗。不要为了强调而大段加粗，也不要把正文中的反引号写成中文引号。

```md
使用 `GET /health` 检查服务；生产环境将 `LOG_LEVEL` 设为 `info`。
```
