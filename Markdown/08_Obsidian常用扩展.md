# 属性（Properties）

属性放在笔记的第一行，用 `---` 包围，并使用 YAML 格式。

```md
---
title: 部署说明
tags:
  - 开发/部署
  - 运维
status: draft
created: 2026-09-14
---
```

属性必须位于文件开头，并使用 YAML 格式。`title`、`tags`、`aliases` 等属性便于在 Obsidian 中检索、筛选和识别笔记。

## 可折叠 Callout

> [!faq]- 为什么不显示？
> 因为它默认折叠，点击标题即可展开。

```md
> [!faq]- 为什么不显示？
> 因为它默认折叠，点击标题即可展开。
```

`[!tip]+` 表示默认展开且可折叠，`[!tip]-` 表示默认折叠。常用类型包括 `note`、`tip`、`info`、`warning`、`danger`、`example`、`question` 和 `todo`。

## 附件路径

本库使用“笔记同级 `assets/<笔记文件名>/` 目录”的附件规则。文件名不含 `.md`，新附件使用 `file-YYYYMMDDHHmmssSSS.<扩展名>` 的命名形式。

图片附件使用标准 Markdown 图片语法，路径相对于当前笔记目录。

```md
![架构图](assets/08_Obsidian常用扩展/file-20260914000000000.png)
```

> [!warning] 示例附件不代表真实文件
> 上例仅展示链接格式，当前笔记并未附带该图片。新增实际附件时，必须同时创建对应文件和目录，避免产生失效引用。
