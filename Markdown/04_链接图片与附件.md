## 链接附件

附件链接可以为 PDF、OpenAPI 定义、压缩包或其他需要下载的文件提供描述性入口。

```md
[下载接口定义](assets/api/openapi.yaml)
```

> [!warning] 路径与附件
> 仓库文档使用 `/`，不要使用 Windows 的 `\`。本笔记库的新附件需放在笔记同级的 `assets/<笔记文件名>/` 目录，并使用相对 Markdown 链接；具体格式见 [Obsidian 常用扩展](08_Obsidian常用扩展.md#附件路径)。

## 链接文本

使用能说明目标的文本，例如 [查看围栏代码块](05_代码与开发文档.md#围栏代码块)，不要写成“[点击这里](05_代码与开发文档.md#围栏代码块)”。链接到标题时，标题锚点由平台生成；标题改名后应重新检查链接。

```md
[查看围栏代码块](05_代码与开发文档.md#围栏代码块)
```
