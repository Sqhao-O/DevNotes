## 接口文档片段

### `POST /api/v1/users`

创建用户。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `email` | string | 是 | 用户邮箱 |
| `name` | string | 是 | 显示名称 |

请求示例：

```json
{
  "email": "dev@example.com",
  "name": "Ada"
}
```

响应示例：

```json
{
  "id": "usr_123",
  "email": "dev@example.com"
}
```
